# Contributing

## Setup
1. Fork the repo.
2. Copy `.env.example` to `.env` and fill your GitHub token and gist ID.
3. Run `npm ci` and `npm run dev`.

## Quality gates
- `npm run lint`
- `npm run typecheck`
- `npm run test`
- `npm run build`

## Pull requests
- Keep commits focused.
- Add tests for behavior changes.
- Update README when public behavior changes.
